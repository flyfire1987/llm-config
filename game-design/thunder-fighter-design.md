# 雷霆战机 - 设计文档

> 单局 5 分钟的竖屏弹幕射击游戏
> 风格参考:雷霆战机 / 1945 / 微信飞机大战
> 平台:Web (Canvas / H5),竖屏

---

## 0. TL;DR

| 项目 | 取值 |
|------|------|
| 单局时长 | **300 秒**(5 分钟) |
| 屏幕方向 | **竖屏** 9:16(720×1280 基准) |
| 主角等级上限 | **Lv.10** |
| 副炮类型(开局选) | **5 选 1** |
| 技能类型 | **3 个**(全屏轰炸 / 冻结 / 无敌) |
| BOSS 数量 | **5 只**(60s / 120s / 180s / 240s / 300s) |
| 精英波次 | **10 波**(每 30 秒) |
| 升级方式 | **每升 1 级 3 选 1**(加血 / 加吸 / 加攻) |
| 副炮升级 | **随主炮等级自动升** |
| 技能刷新 | **30 秒 1 次,3 选 1** |

## 1. 单局时间线 (300 秒)

```
0s          60s         120s        180s        240s        300s
|           |           |           |           |           |
├─ 起始 ──── BOSS#1 ──── BOSS#2 ──── BOSS#3 ──── BOSS#4 ─── BOSS#5
│           ↑ 难度 ×1.0  ×1.3        ×1.6        ×2.0        ×2.5
│
├─ 30s 精英波(2~3 只)──────────────────────────────────────────┤
│   30 60 90 120 150 180 210 240 270 300(共 10 波)            │
└──────────────────────────────────────────────────────────────┘

技能刷新(每 30 秒):30/60/90/120/150/180/210/240/270/300
敌机种类随时间解锁:0~60s 用 Lv1~3,60~180s 加 Lv4~6,180s+ 加 Lv7~10
```

## 2. 主角 (玩家飞机)

### 2.1 基础属性 (Lv.1 初始值)

| 属性 | 数值 | 说明 |
|------|------|------|
| 血量 (HP) | **100** | 主角血量 |
| 吸血 | **5%** | 每次伤害的 5% 转 HP(对 BOSS/精英 50% 效率) |
| 攻击力 | **10** | 主炮单发伤害 |
| 经验值 | **0 / 100** | 满 100 升 1 级 |

### 2.2 主角视觉

- 机型:**当前只有 1 种**(开局固定)
- 尺寸:**宽 48px / 高 56px**(基准 720×1280 屏幕)
- 主炮弹道宽度:**54px**(略大于机身宽度 48px,留 3px 边距)
- 移动:触屏拖动 / 鼠标拖动 / 键盘 WASD+空格
- 飞机血条:屏幕左上角(100px 红条)

### 2.3 主角升级路线 (Lv.1 → Lv.10)

| Lv | 升级所需经验 | 主炮形态 | 主炮射速 | 升级选项(3 选 1) |
|----|------|----------|----------|------------------|
| 1 | 100   | 单发直弹 | 6 发/秒 | — |
| 2 | 250   | 单发直弹 | 7 发/秒 | 加 HP / 加吸血 / 加攻 |
| 3 | 450   | 二连发   | 7 发/秒 | 加 HP / 加吸血 / 加攻 |
| 4 | 700   | 三连发   | 7 发/秒 | 加 HP / 加吸血 / 加攻 |
| 5 | 1000  | 三连发(宽) | 8 发/秒 | 加 HP / 加吸血 / 加攻 |
| 6 | 1400  | 五连发(扇形) | 8 发/秒 | 加 HP / 加吸血 / 加攻 |
| 7 | 1900  | 五连发(扇形 + 穿透) | 8 发/秒 | 加 HP / 加吸血 / 加攻 |
| 8 | 2500  | 七连发(扇形 + 穿透) | 9 发/秒 | 加 HP / 加吸血 / 加攻 |
| 9 | 3200  | 九连发(扇形 + 穿透) | 9 发/秒 | 加 HP / 加吸血 / 加攻 |
| 10| 4000  | 终极弹幕(全屏 13 弹扇形) | 10 发/秒 | — (已满级) |

**说明**:
- 升级经验递增,平均 **~50 秒升 1 级**,5 分钟大约升到 Lv.6(经验值是软上限,等级天花板是 Lv.10)
- 主炮形态只受等级影响,**不跟升级选项走**(升级选项只加属性)

### 2.4 升级选项数值表

| 选项 | Lv.1 基础 | 每级增量 | Lv.10 累计 |
|------|----------|----------|----------|
| 加 HP | 100 | **+20** | 280 |
| 加吸血 | 5% | **+1.5%** | 18.5% |
| 加攻击 | 10 | **+3** | 37 |

> 三选一的策略取舍:加 HP 撑得住但打不出输出,加吸血续航高但单挑乏力,加攻击爆发高但脆皮。
> 5 分钟单局:**理论上可拿 9 次升级**,不同路线强度差约 ±30%。

## 3. 副炮 (开局 5 选 1,随主炮升级自动提升)

### 3.1 5 种副炮

| # | 副炮 | 形态 | Lv.1 数值 | 升级跟随 | 优点 | 缺点 |
|---|------|------|----------|----------|------|------|
| **A** | 高伤害导弹 | 直线 + 爆炸圈 | 单发 40 伤,半径 60px | 等级↑ → 伤害 +50%、爆炸半径 +20% | 单发伤害高,打 BOSS 利器 | 攻速慢(1.5s/发) |
| **B** | 追踪导弹 | 锁定最近敌机 | 单发 15 伤,追踪 3s | 等级↑ → 跟踪速度 +30%、伤害 +40% | 几乎不漏怪,清理小怪神器 | 攻速中等(1s/发) |
| **C** | 激光(穿透) | 持续射线 | 单束 8 伤/s,**穿透**所有敌机 | 等级↑ → 宽度 +50%、伤害 +50% | 持续输出 + 穿透,扫屏王 | 范围固定,被弹分散输出低 |
| **D** | 散弹 | 前方锥形 5 发 | 每发 6 伤,扇角 30° | 等级↑ → 弹数 5→7→9、伤害 +40% | 中近距离无敌,场面壮观 | 单发伤害低,远距离散开 |
| **E** | 爆炸弹 | 直射 + 弹跳 | 单发 20 伤,弹 3 次 | 等级↑ → 弹跳次数 +1、伤害 +50% | 反弹清密集怪,难躲 | 距离衰减 |

### 3.2 副炮升档(Lv.1/4/7/10)

| 副炮 | Lv.1 | Lv.4 | Lv.7 | Lv.10 |
|------|------|------|------|------|
| A 高伤导弹 | 40 伤 / 半径 60 | 56 / 68 | 72 / 76 | 90 / 84 |
| B 追踪导弹 | 15 伤 / 3s 追踪 | 19 / 3.6s | 24 / 4.2s | 30 / 5s |
| C 激光 | 8 伤/s / 宽 30px | 10 / 39 | 12 / 48 | 16 / 60 |
| D 散弹 | 6 伤 × 5 发 | 7 × 6 | 8 × 7 | 10 × 9 |
| E 爆炸弹 | 20 伤 / 弹 3 次 | 25 / 3 | 30 / 4 | 40 / 5 |

> 副炮与主炮**触发时机错开**:主炮射速 6~10/s,副炮射速 1~2/s,**形成密度感**(主炮压制远 + 副炮特色)。

## 4. 技能 (30 秒刷新 1 次,3 选 1)

### 4.1 技能列表

| # | 技能 | 效果 | 持续 | 冷却 |
|---|------|------|------|------|
| **1** | 💥 **全屏轰炸** | 全屏 AOE,所有敌机受到 **主炮攻击力 × 30** 的伤害 | 1 次性(瞬时) | 30s |
| **2** | ❄️ **冻结** | 全屏敌人**冻结 3 秒**(不能移动/不能发射),精英冻 1.5s,BOSS 无视 | 3 秒 | 30s |
| **3** | 🛡️ **无敌** | 主角**3 秒无敌帧**,期间穿弹幕不受伤 | 3 秒 | 30s |

### 4.2 技能刷新机制

```
游戏内时间轴:
0s      30s     60s     90s     120s    ...     300s
│       │       │       │       │
开局    首次刷   二次刷   三次刷   四次刷
        (3 选 1) (3 选 1) (3 选 1) (3 选 1)
```

- 0~30 秒之间**不刷技能**,给玩家熟悉节奏
- 30 秒节点开始,**每次刷新 3 选 1**,玩家选一个使用
- 300s 关卡结算时,未用的技能作废

#### 4.4.1 布局规范

| 项 | 取值 |
|----|------|
| 位置 | 屏幕**最右侧**,距右边缘 8px |
| 方向 | **竖向排列**(上下叠,共 3 个) |
| 单个尺寸 | 60px × 60px |
| 间距 | 12px |
| 总高度 | 60×3 + 12×2 = **204px** |
| 屏幕对齐 | **垂直居中**(top: 50%, transform: translateY(-50%)) |
| 层级 | z-index: 50(盖在游戏内容上) |

#### 4.4.2 视觉态

| 状态 | 表现 |
|------|------|
| **READY**(可点) | 满色 + 蓝色外发光(`box-shadow: 0 0 16px #3b82f6`) |
| **CD**(冷却中) | 灰度 60% + 上面叠一个深色蒙层(渐变到下方透明) |
| **EMPTY**(未刷新,开局 0~30s) | 完全透明 + 灰色边框虚线,提示"等刷新" |
| **FLASH**(刚刷新完) | **脉冲动画** 0.6s:scale(1)→1.15→1,opacity 0→1,蓝色光环扩散 2 次 |

#### 4.4.3 刷新动画(核心!)

当 30s 节点到达,3 个技能**同时**触发刷新动画:

```
时间  0.0s   0.1s   0.2s   0.3s   0.4s   0.5s   0.6s
      │                                                  │
按钮   ▢     ⬆️1.15 ⬇️1.0  ⬆️1.15 ⬇️1.0  ⬆️1.15 ⬇️1.0 ▢
光晕   ▢     扩散   消散   扩散   消散   扩散   消散  ▢
颜色   灰   →  亮蓝(脉冲)      →  亮蓝(READY态)      →  可点击
```

**具体动画**(`@keyframes skill-flash`):
```css
@keyframes skill-flash {
    0%   { transform: scale(0.6); opacity: 0;   box-shadow: 0 0 0 0 #3b82f6; }
    40%  { transform: scale(1.2); opacity: 1;   box-shadow: 0 0 0 14px rgba(59,130,246,0); }
    70%  { transform: scale(0.95); opacity: 1;  box-shadow: 0 0 0 7px rgba(59,130,246,0); }
    100% { transform: scale(1.0); opacity: 1;    box-shadow: 0 0 16px 4px #3b82f6; }
}
```

- 持续 0.6s
- `cubic-bezier(0.34, 1.56, 0.64, 1)`(轻微回弹)
- 同时触发的还有**屏幕震动 0.1s**(横向 ±4px,强化"刷新感")
- 顶部弹一行文字 `✨ 技能已刷新`(白色描边,1s 后淡出)

#### 4.4.4 CD 倒计时圆环

CD 状态下,按钮中心数字显示剩余秒数(向下取整),按钮**外围**有一个 SVG 圆环从满到空:

```html
<svg class="cd-ring" viewBox="0 0 60 60">
    <circle cx="30" cy="30" r="26"
            stroke="#3b82f6" stroke-width="3" fill="none"
            stroke-dasharray="163.36"  <!-- 2πr = 163.36 -->
            stroke-dashoffset="..."   <!-- 0=满,163.36=空 -->
            transform="rotate(-90 30 30)"/>
</svg>
```

JS 每帧更新 `stroke-dashoffset`:
```js
const pct = remaining / cooldown;          // 0~1
ring.style.strokeDashoffset = 163.36 * (1 - pct);
```

#### 4.4.5 点击交互

| 状态 | 点击行为 |
|------|----------|
| READY | 立即使用 + 切到 CD 态 + 触发技能特效 + 顶部 log |
| CD | 不响应 + 短震反馈(0.05s) |
| EMPTY | 提示 "技能未刷新" + 灰色闪烁 0.3s |

#### 4.4.6 与其他 UI 的位置关系

| 元素 | 位置 |
|------|------|
| 技能面板 | 右侧 margin-right: 8px |
| 主游戏内容 | max-width: calc(100% - 80px)(留 80px 给技能列) |
| 暂停按钮 | 左上角(原位) |
| 时间/击杀 | 右上角(技能列上方) |

> 移动端竖屏(< 720px)技能列自动缩小到 50×50,间距 8px。

### 4.3 技能与升级/副炮的配合

| 技能 | 最强配合 |
|------|----------|
| 全屏轰炸 | 加攻击 → 30 倍伤害爆炸式;副炮 C 激光打残留 |

## 11. 风险与待确认

| 项 | 风险 | 建议 |
|----|------|------|
| **Lv.10 上限合理性** | 5 分钟可能升不到 Lv.10 | 已在 §2.3 标注:Lv.10 是软上限,平均 Lv.6 完赛 |
| **副炮 5 选 1 vs 3 选 1** | 5 种偏多 | MVP 可做 3 种,后续扩展到 5 |
| **技能 3 选 1 vs 顺序出现** | 用户原文说"3 个"未明"3 选 1" | 暂按 3 选 1 设计(类似 roguelike 快感),如果想固定 30/60/90 各出固定技能,改 §4.2 |
| **精英召唤时是否计入精英上限** | BOSS#5 P3 召唤 2 只精英,可能太挤 | MVP 可关掉召唤,只保留弹幕形态 |
| **弹幕数过多卡顿** | Canvas 2D 弹幕 > 200 可能掉帧 | 子弹对象池 + off-screen culling |
| **平衡数据** | 现在是拍脑袋数字 | MVP 上线后收集数据,§5.2 难度系数可调 |
