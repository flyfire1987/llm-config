# 🩸「无尽回响 / Echoes of Eternity」— Web 版 Roguelike 割草爽游

> **目标**:15-20 分钟一局,单手操作(Web 端鼠标点击 / 触屏),仿《吸血鬼幸存者》骨架 + 多个技能/武器系列 + 神器进化(Evolution)机制 + 爽感叠加系统。
>
> **技术栈建议**:TypeScript + PixiJS / Phaser 3(2D WebGL 渲染),Web Worker 处理怪物 AI 与伤害计算,RoseDB 存档(IndexedDB 包装)。

---

## 0. 设计目标(写在最前面,避免后期跑偏)

| 维度 | 目标值 | 验收标准 |
|------|--------|----------|
| 单局时长 | 15-20 分钟 | 90% 玩家在 12-22 分钟内死亡或通关 |
| 同屏怪物数 | 500-1500 | 中端笔电(集显)30fps 稳定 |
| 同屏伤害数字 | 50-200 | 不堆满屏幕,关键数字 1.5x 字号 |
| 学习成本 | 5 分钟会玩,30 分钟精通 | 首次开新角色无需读文档 |
| 重玩深度 | 单角色 50h+ 不腻 | 至少有 3 个"换流派重开"的理由 |
| 商业化留存 | 7 日留存 ≥ 25% | 解锁驱动 + 赛季通行证 |

## 1. 核心循环(One-Loop)

```
┌──────────────────────────────────────────────────────────────┐
│  开局选角 / 选武器 → 进入地图(倒计时 00:00)                  │
│                       ↓                                      │
│  击杀小怪 → 掉落经验宝石 → 升级 → 选 1 选 1(卡牌三选一)     │
│                       ↓                                      │
│  每 60s 触发一波精英怪(倒计时 Boss 警告)                     │
│  每 2min  触发一次 Boss(血条 + 阶段机制)                     │
│  每 5min  触发"狂热时刻"(怪物数量 x3,经验 x2,30s)          │
│                       ↓                                      │
│  期间:拾取宝箱 → 解锁新技能 / 升级旧技能 / 拾取神器          │
│                       ↓                                      │
│  死亡或通关(20min 击败最终 Boss) → 结算 → 永久解锁碎片       │
│  碎片用于:角色解锁 / 武器解锁 / 神器图鉴 / 传承升级          │
│                       ↓                                      │
│              再次开局(角色 + 武器 + 初始神器可继承)          │
└──────────────────────────────────────────────────────────────┘
```

**关键设计点**:
- **15-20 分钟的节奏切分**: 0-2min 暖场 / 2-5min 流派定型 / 5-10min 流派成神 / 10-15min 爽感巅峰 / 15-20min 极限挑战
- **死亡不是失败**: 永久碎片 + 排行榜分数,**不死也能解锁**,但死亡=碎片 +50%
- **重玩动力**: 每个角色有 3 个"传承升级树",**部分跨角色通用**,鼓励换角色

### 2.2 角色机制差异点(避免"换皮"感)

| 差异点 | 说明 |
|--------|------|
| **基础移动速度** | 320-380 px/s 区间内,影响"走位舒适度" |

## 3. 武器 / 技能系统(核心)

### 3.1 三层武器结构(借鉴 VS 但强化)

```
┌─────────────────────────────────────────────────────┐
│  L1. 基础武器(Base Weapon)                           │
│      角色自带 / 初始武器,数量固定(1 个)              │
│      升满 Lv.8 后可进化 → L2                         │
├─────────────────────────────────────────────────────┤
│  L2. 进化武器(Evolved Weapon)                       │
│      Lv.8 满级 + 持有对应神器 → 解锁进化             │
│      解锁 Lv.9-∞ 等级,属性质变                       │
│      总数 = L1 总数(每个 L1 对应一个 L2)             │
├─────────────────────────────────────────────────────┤
│  L3. 终极武器(Ultimate Weapon)                      │
│      L2 升满 Lv.20 + 持有"组合神器"(2 个神器)        │
│      解锁形态变化(比如飞弹 → 飞弹 + 追踪 + 穿透)     │
│      每个角色 1 个终极武器                            │
└─────────────────────────────────────────────────────┘
```

### 3.2 武器系列(7 大流派,每个流派 4-6 把武器)

> 角色可以**跨流派**装备,但**同流派有"羁绊加成"**,引导玩家"专精"或"全通"。

#### 系列 A: 🔮 奥术(Arcane) — 魔法伤害 / 弹道
- **奥术飞弹**: 直射,命中爆炸(小 AOE)
- **雷电链**: 命中后弹射(最多 5 跳)
- **星辰陨落**: 随机区域陨石(2s 延迟,可躲避)
- **奥术洪流**: 持续激光(穿透,但伤害中等)
- **虚空撕裂**: 直线黑洞(吸怪 + 持续伤害)

#### 系列 B: ⚔️ 钢铁(Steel) — 物理伤害 / 近战
- **旋转巨斧**: 围绕角色旋转(同时攻击 8 个目标)
- **血腥扫帚**: 向前扇形(宽 AOE,但有 CD)
- **剑刃风暴**: 全屏环斩(无敌帧 0.5s)
- **回旋飞斧**: 直线飞斧(命中返回,可二次攻击)
- **巨锤震击**: 蓄力 1s 后重击(范围 + 击退)

#### 系列 C: 🏹 猎手(Hunter) — 物理伤害 / 投射
- **飞刀连射**: 高速多发(单发低伤,但数量多)
- **毒箭**: 命中附加 DOT(3s,持续掉血)
- **散弹枪**: 扇形多发(近身爆炸)
- **寒冰箭**: 命中减速 -50%
- **穿刺长矛**: 高伤单发(穿透 5 个目标)

#### 系列 D: 🔥 元素(Element) — 元素伤害 / 范围
- **火球术**: 命中点燃(AOE + DOT)
- **冰霜新星**: 周围 360° 释放(减速 + 冻结精英)
- **闪电领域**: 脚下持续放电(每 0.5s 一次)
- **毒气瓶**: 留下毒云(持续 5s)
- **圣光审判**: 召唤光柱(垂直范围,延迟 1s)

#### 系列 E: 💀 暗影(Shadow) — 暗影伤害 / 召唤
- **暗影蝙蝠**: 召唤 3 只,自动攻击
- **骷髅兵**: 召唤 2 个近战
- **诅咒之触**: 命中后概率触发"即死"(对精英无效)
- **暗影步**: 闪现 + 留下残影(残影自动攻击)
- **吸血鬼之触**: 命中回血

#### 系列 F: 🌿 自然(Nature) — 物理伤害 / 控场
- **荆棘藤蔓**: 减速 + 持续伤害
- **毒蘑菇**: 范围内持续喷毒
- **树人守卫**: 召唤 1 个高血量肉盾
- **风刃**: 直线高速风刃(推开敌人)
- **荆棘甲**: 反伤(被攻击也输出)

#### 系列 G: ✨ 光辉(Light) — 神圣伤害 / 增益
- **神圣锤**: 落锤 + 击退
- **天使号角**: 全队(玩家 + 召唤物)+10% 攻击
- **治愈之光**: 被动回血(每秒 1% 最大血量)
- **审判之剑**: 对低血敌人伤害 +50%
- **圣光护盾**: 受伤时概率触发(2s 无敌)

### 3.3 技能与武器的关系

> **简化决策**: **不分离技能和武器**,每个"技能"= 一把武器,但有"主动 vs 被动"之分。

| 类型 | 数量上限 | 触发方式 | 升级方式 |
|------|----------|----------|----------|
| 主动武器 | 6 个 | 自动攻击,无需操作 | 拾取后升级卡牌三选一 |
| 被动装备 | 6 个 | 永久被动效果 | 同上 |
| 神器 | 3 个 | 改变规则 / 提供进化 | 拾取后即生效,可替换 |

> 玩家**不需要点击使用技能**,所有技能自动触发。**鼠标只用来移动 + 选择卡牌**。

## 5. ⭐ 神器进化系统(Evolution — 本游戏核心爽点)

### 5.1 神器定义

**神器(Relic)** = 一件**改变规则**的物品,持有时永久生效,可被替换但**死亡时 30% 掉落**。

### 5.2 神器分类

#### A. 武器进化神器(Evolution Relic)
> **持有 Lv.8 满级武器 + 持有对应神器 = 自动进化为 Lv.9 武器**

**示例**:

| 武器 | 进化神器 | 进化后效果 |
|------|----------|------------|
| 奥术飞弹 | 法师之眼 | **奥术弹幕**: 投射物数 +3,弹道速度 +50%,命中范围 +30% |
| 旋转巨斧 | 血祭坛 | **血腥回旋**: 旋转数 +1,命中回血(每杀 1 个回 1% 血) |
| 飞刀连射 | 鹰眼吊坠 | **夺命飞刀**: 暴击率 +20%,暴击伤害 +50%,命中减速 30% |
| 闪电领域 | 风暴之眼 | **雷霆风暴**: 范围 +50%,每 3 次攻击触发一次连锁闪电 |
| 暗影蝙蝠 | 吸血鬼之牙 | **血族狂潮**: 召唤数 +3,每次攻击吸取 2% 伤害作为血量 |
| 神圣锤 | 天使羽毛 | **天堂之锤**: 落锤 + 圣光爆(2x 范围),击退 + 击晕精英 1s |
| 毒气瓶 | 剧毒精华 | **瘟疫之源**: 持续时间 5s → 10s,毒伤 +200%,死亡 50% 触发二次毒云 |

#### B. 通用神器(Global Relic)
> 改变游戏规则 / 提供**跨流派加成**

**示例**:
- **怀表(Watch)**: 怪物移速 -15%,但**经验获取 +20%**(控场流核心)
- **贪婪金币(Golden Coin)**: 击杀 +20% 金币,但**Boss 血量 +30%**
- **死亡笔记(Death Note)**: 每 30 秒一次,即死一只精英(Boss 无效)
- **血瓶(Blood Vial)**: 拾取宝石时 5% 概率回 1% 血
- **磁铁(Magnet)**: 拾取半径 +50%
- **复制之镜(Mirror)**: 30% 概率触发第二次攻击
- **时光沙漏(Hourglass)**: 每 3 分钟一次,时间倒回 10 秒
- **无尽之袋(Bag of Holding)**: 装备上限 +1(6→7)

#### C. 终极神器(Ultimate Relic)
> 持有 **2 个武器进化神器 + 1 个通用神器 = 终极形态**

**示例**:
- **奥术之心**: 持有 法师之眼 + 怀表 → **奥术之心**: 所有奥术武器伤害 +100%,每 30s 全屏奥术爆破
- **猩红盛宴**: 持有 血祭坛 + 吸血鬼之牙 → **猩红盛宴**: 击杀完全回血,暴击时 50% 概率触发"血爆"(周围敌人 50% 血量)
- **雷霆之主**: 持有 风暴之眼 + 死亡笔记 → **雷霆之主**: 闪电链跳数 +3,精英 50% 概率被即死

### 5.3 神器池(总 80+,分稀有度)

| 稀有度 | 数量 | 掉落来源 |
|--------|------|----------|
| 普通 | 30 | 全程可掉,基础强化 |
| 稀有 | 25 | Lv.5+ 可掉 |
| 史诗 | 15 | Lv.10+ 可掉 |
| 传说 | 8 | Boss 掉落 / 宝箱 |
| 至高(终极神器) | 5 | 通关 / 隐藏 Boss |

### 5.4 进化触发 UX

```
[拾取神器] → 屏幕中央弹出提示:
"获得神器: 法师之眼"
"持有 Lv.8 武器: 奥术飞弹"
"⚡ 进化! 奥术飞弹 → 奥术弹幕 ⚡"
[3 秒光柱效果 + 屏幕震动 + 50+ 伤害数字爆开]
```

**关键**: 进化是**屏幕级的爽点反馈**,不是默默生效,要让玩家"看见"自己变强了。

## 7. 爽感设计(15 条具体原则)

### 7.1 屏幕层

| 原则 | 实现 |
|------|------|
| **伤害数字** | 暴击 1.5x 字号,击杀 +1 段跳,终伤 2x 字号 + 金色描边 |
| **击杀粒子** | 普通=灰雾,精英=彩色光,神话=全屏震屏 + 慢动作 0.3s |
| **拾取反馈** | 经验宝石飞向玩家时拉出"光丝",金装掉落有"上抛+落地" |
| **暴击反馈** | 屏幕白闪 0.05s + 怪物击退 5px |
| **进化反馈** | 角色全屏光柱 + 50+ 数字爆开 + 神器文字 2s 居中显示 |

### 7.2 数值层(关键的"指数曲线")

```
伤害 = 基础 × (1 + 等级)^1.3 × 神器加成 × 暴击 × 羁绊
经验 = 怪物基础经验 × 等级系数 × 狂热时刻(2x)
怪物血量 = 基础 × (1 + 时间/min)^2.5
怪物伤害 = 基础 × (1 + 时间/min)^1.5
```

**关键**: **怪物血量曲线 > 怪物伤害曲线** → 时间越长越考验"瞬间爆发"而不是"血量",逼出"秒杀流"。

### 7.3 心理层(节奏感)

- **30s 一次精英** → "我变强了"
- **2min 一次 Boss** → "我流派成了"
- **5min 一次狂热** → "我能清场"
- **10min 第一次濒死** → "这才是真挑战"
- **15min 解锁终极武器** → "我现在是神"
- **20min 通关** → "我超越了 99% 的玩家"

### 7.4 反馈层(让爽感"看见")

| 事件 | 反馈 |
|------|------|
| 升级 | 角色全身光闪 0.2s,卡牌从屏幕外飞入 |
| 拾取神器 | 屏幕中央文字 + 角色周围粒子 |
| 进化 | 全屏 0.5s 慢动作 + 神器图标旋转 |
| 暴击 | 伤害数字 1.5x + 屏幕白闪 |
| 精英击杀 | 彩色粒子 + 屏幕震动 |
| Boss 击败 | 全屏震动 + Boss 解体动画 + 必掉神器光柱 |
| 通关 | 4K 慢镜头 + 角色特写 + "通关" 大字 |

## 9. 持久化与解锁(Re-playability)

### 9.1 局内经济

| 资源 | 用途 | 死亡是否保留 |
|------|------|--------------|
| 金币 | 局内无用途,**局末兑换碎片** | 50% 保留 |
| 经验 | 局内升级 | 0% 保留 |
| 神器 | 局内效果 | 30% 保留 |
| 碎片 | **永久货币** | 100% 保留 |
| 排行榜分 | 周榜 / 月榜 | 100% 保留 |

### 9.2 碎片经济

```
击杀 Boss → +50~200 碎片
通关 → +500 碎片
挑战模式(无伤 / 速通)→ +1000 碎片
死亡 → +50~300 碎片(基于存活时间)

碎片消耗:
- 解锁新角色: 500-2000
- 解锁新武器: 100-500
- 解锁新神器: 50-300
- 升级角色传承: 100-1000(每次升级 +10%)
- 赛季通行证: 5000(10 级奖励)
```

### 9.3 角色传承(跨角色通用,留住换角色动力)

| 升级 | 效果 | 跨角色 |
|------|------|--------|
| Lv.1 | 初始血量 +10% | ✓ |
| Lv.2 | 拾取半径 +10% | ✓ |
| Lv.3 | 经验获取 +5% | ✓ |
| Lv.4 | 起始武器 Lv.1 → Lv.2 | ✗(仅本角色) |
| Lv.5 | 复活时保留 50% 神器 | ✓ |
| Lv.10 | 终极武器 Lv.20 → Lv.25 上限解锁 | ✗ |

## 12. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 后期数值崩坏 | 数字亿亿亿,看不出爽感 | 软上限 + 单位自动转换(K/M/B/T) |
| 卡牌三选一太单一 | 重玩单调 | 加"逆选"(可选 1 个 + 跳过一个) |
| 进化太难触发 | 玩家不知道有这个机制 | **首次满足条件时,屏幕强提示** |
| 移动端性能差 | 直接劝退 | M1 不做移动端,M2 末期再适配 |
| 角色平衡 | 夜莺 vs 薇拉差距过大 | 内置"角色强度评分",每月调一次 |
| 单局太长 | 玩家中途退出 | **"存档点"机制**:每 5min 可退出,下次继续 |
